ระบบนี้อธิบาย "ความร้อนในชุมชน" และตอบโจทย์งานวิจัยอย่างไร?

เชื่อมโยงข้อมูล 3 มิติ ได้แก่ สัณฐานอาคารจาก building.shp + ภาพถ่ายดาวเทียม Landsat 8/9 (30 m) + การเดินวัดอากาศจริงระดับคนเดินเท้าด้วย IoT (1 Hz) ลงบนกริดมาตรฐานขนาด 90 × 90 เมตร เพื่อแยกแยะว่าความร้อนในชุมชนเกิดจาก "ความหนาแน่นอาคาร" หรือ "การขาดพื้นที่สีเขียว" มากน้อยเพียงใด

ขั้นที่ 1 · ข้อมูลตั้งต้น 3 แหล่ง

Physical + Satellite + Human-level IoT

  • building.shp (BMA / Open Buildings): คำนวณสัดส่วนพื้นที่อาคาร (builtup_pct), จำนวนหลัง, จำนวนชั้นเฉลี่ย และ FAR
  • Landsat 8/9 (30 m): คำนวณอุณหภูมิพื้นผิว (LST), พืชพรรณ (NDVI) และสิ่งปลูกสร้าง (NDBI)
  • IoT Walking & Stationary (1 Hz): วัดอุณหภูมิอากาศจริง (temp_c), ความชื้น, แสง และเสียงระดับทางเดินเท้า
ขั้นที่ 2 · การรวมข้อมูลเชิงพื้นที่

90 m Spatial Grid Aggregation

  • กำหนดขนาดกริด 90 × 90 ม. (3×3 พิกเซล Landsat) เพื่อลดความคลาดเคลื่อนของพิกัด GPS ขณะเดิน
  • คำนวณค่าเฉลี่ยถ่วงน้ำหนักพื้นที่สำหรับ building.shp และค่าเฉลี่ยดาวเทียมในแต่ละเซลล์
  • จับคู่ข้อมูล IoT แบบ Window (09:30–11:30 น.) เพื่อให้ตรงเวลาที่ดาวเทียมโคจรผ่านพื้นที่ศึกษา
ขั้นที่ 3 · แบบจำลองอธิบายความร้อน

Statistical & Spatial Modeling

  • Multiple Regression (S3/S4): หาค่าสัมประสิทธิ์มาตรฐาน ($\beta^*$) เพื่อเทียบน้ำหนักของ NDVI vs อาคาร
  • Random Forest Importance (S5): จับความสัมพันธ์แบบไม่เป็นเส้นตรง (Non-linear) ของสัณฐานเมือง
  • Getis-Ord $G_i^*$ & Moran's $I$: ระบุพิกัดกลุ่มอาคารที่เป็น "เกาะความร้อนวิกฤต" อย่างมีนัยสำคัญทางสถิติ

ตารางเปรียบเทียบผลลัพธ์จากข้อมูลของเรา (กำลังโหลด…) เทียบกับงานวิจัย UHI

ค่าในคอลัมน์ "ผลที่คำนวณได้จากระบบเรา" อัปเดตอัตโนมัติตามช่วงเวลาที่เลือกด้านบน เพื่อใช้เขียนอภิปรายผล (Discussion) เทียบกับงานวิจัยด้านเกาะความร้อนเมือง (Urban Heat Island)

ประเด็นการอธิบายความร้อน วิธีคำนวณ / ตัวชี้วัด ผลที่คำนวณได้จากระบบเรา เกณฑ์อ้างอิงจากงานวิจัย UHI การตีความผลสำหรับชุมชน

สรุปสูตรและวิธีการคำนวณทางวิชาการ (Calculation Reference)

โมดูล / สมการ สูตร / อัลกอริทึม ความหมายในการอธิบายความร้อนชุมชน
ความหนาแน่นอาคาร (building.shp) builtup_pct = (Σ Area_bldg / 8100 m²) × 100
FAR = Σ (Area_bldg × Floors) / 8100 m² 		สะท้อนมวลความร้อน (Thermal Mass) และการบังลม (Wind Blocking) ของกลุ่มอาคารในบล็อก 90×90 ม.
ดัชนีพืชพรรณ & สิ่งปลูกสร้าง NDVI = (NIR - Red) / (NIR + Red)
NDBI = (SWIR - NIR) / (SWIR + NIR) 		วัดความสามารถในการคายระเหยน้ำลดความร้อน (Evapotranspiration) เทียบกับพื้นผิวคอนกรีต/หลังคา
แบบจำลองอธิบาย LST (S3) LST = β₀ + β₁(NDVI) + β₂(NDBI) + β₃(builtup_pct) + ε
เปรียบเทียบค่ามาตรฐาน β* = β · (SD_x / SD_y)		 บอกได้ว่าหากเพิ่มพื้นที่สีเขียว 1 SD หรือลดความหนาแน่นอาคาร 1 SD จะลดอุณหภูมิพื้นผิวได้กี่ส่วนเบี่ยงเบนมาตรฐาน
แบบจำลองอุณหภูมิอากาศจริง (S4) AirTemp_IoT = β₀ + β₁(LST) + β₂(NDVI) + β₃(builtup_pct) + ε เชื่อมความร้อนจากภาพถ่ายดาวเทียมลงสู่ระดับความสูง 1.5 ม. ที่คนเดินเท้าในชุมชนรู้สึกจริง (Microclimate Coupling)
ดัชนีจุดร้อนชุมชน (Getis-Ord Gᵢ*) Gᵢ* = [Σ wᵢⱼxⱼ - X̄ Σ wᵢⱼ] / [S · √((n Σ wᵢⱼ² - (Σ wᵢⱼ)²)/(n-1))]
รัศมีเพื่อนบ้าน d = 300 m		 คัดกรองเฉพาะกลุ่มอาคารที่ร้อนสูงต่อเนื่องเป็นบริเวณกว้าง (Hot Spot 95%/99%) ไม่ใช่จุดร้อนโดดเดี่ยว
