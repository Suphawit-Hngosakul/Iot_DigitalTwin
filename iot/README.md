# iot/

ทุกอย่างที่อยู่บนตัวอุปกรณ์ ทั้งแบบเดินเก็บ (walk-01, walk-02) และแบบตั้งประจำจุด (station-xx)

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `firmware/` | Arduino sketch ของ ESP32 |
| `hardware/` | ตารางขา, รายการอุปกรณ์, ไฟล์ 3D กล่อง |
| `simulator/` | สคริปต์ Python จำลองอุปกรณ์ (ส่ง CSV/WSS แบบเดียวกับของจริง) |
