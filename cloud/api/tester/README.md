# cloud/api/tester — หน้าทดสอบ API #18

หน้า HTML ไฟล์เดียวสำหรับนักพัฒนาใช้ลอง API และดูข้อมูลบนแผนที่ **ไม่ใช่เว็บจริง** (เว็บจริงคือ #35 ใน `web/`)

## ใช้ยังไง

1. เปิดผ่าน localhost (ต้องมีเน็ต เพราะโหลด MapLibre, ECharts และแผนที่ฐาน OSM / Esri (ไม่ต้องใช้ API key)):
   ```
   cd cloud/api/tester
   python -m http.server 8000
   ```
   แล้วเปิด http://localhost:8000 (ถ้าใช้แค่โหมดข้อมูลตัวอย่าง จะดับเบิลคลิก `index.html` ก็ได้)
2. ยังไม่ได้ deploy ให้ติ๊ก **ข้อมูลตัวอย่าง** ได้เลย หน้าเว็บจะจำลองการเดินรอบเขตหลักสี่ โดยใช้กติกาเดียวกับ `handler.py` (ช่วงเวลา, 400/404)
3. deploy แล้วให้เอา `terraform output api_url` มาใส่ช่อง API URL เอาติ๊กข้อมูลตัวอย่างออก แล้วกด **โหลด /devices**

## มีอะไรบ้าง

- เลือกเครื่องได้ และเห็นชั่วโมงล่าสุดที่ publish (จาก `/devices`)
- `/latest` จะปักหมุดตำแหน่งล่าสุดบนแผนที่
- `/readings` ทั้ง 1min และ 1s แสดงเป็นจุดบนแผนที่ ระบายสีตามค่าที่เลือก (dB, อุณหภูมิ, ความชื้น, แสง ฯลฯ) พร้อมเส้นทางและกราฟเวลา ชี้ที่กราฟแล้วจุดบนแผนที่จะขยับตาม
- `/quality` แสดงเป็นตาราง loss ต่อชั่วโมง ถ้าเกิน 5% จะเป็นสีส้ม
- ปุ่มเช็คเกณฑ์ใน spec 40 §5: ความเร็วก่อนและหลัง cache, 400 เมื่อช่วงเวลาเกิน, 404 เมื่อไม่มีเครื่องนั้น
- Request log แสดง status, เวลา, ขนาด และ JSON ของทุก request
- แท็บ **Dashboard** เลือกเครื่องกับวันที่ แล้วจะแสดง
  - การ์ดค่าล่าสุด (เสียง, อุณหภูมิ, ความชื้น, แสง) จำนวนชั่วโมงที่มีข้อมูล และ loss ของวันนั้น (ปกติ < 2%, เริ่มหาย 2–5%, หายเยอะ > 5%)
  - แผนที่จุดที่วัด ระบายสีตาม dB(SPL)
  - กราฟรายนาทีของเสียง (เส้นเฉลี่ย + แถบต่ำสุด–สูงสุด), อุณหภูมิ, ความชื้น, แสง แยกกราฟละตัวแปร
  - กราฟแท่ง loss ต่อชั่วโมง
  - ติ๊กให้รีเฟรชเองทุก 5 นาทีได้ (pipeline publish ชั่วโมงละครั้ง)

## หมายเหตุ

- ห้ามเปิดจากไฟล์ตรงๆ เมื่อเรียก API จริง เพราะเบราว์เซอร์จะส่ง `Origin: null` และ API Gateway จะไม่ใส่ `Access-Control-Allow-Origin` ให้ origin `null` แม้ตั้ง `["*"]` ไว้ (ทดสอบแล้ว 2026-11-18) ทำให้ติด CORS ถ้าล็อก `api_allowed_origins` เป็นโดเมนเว็บแล้ว ให้เพิ่ม `http://localhost:8000` เข้าไปด้วย
- เวลาเป็นเวลาไทยทั้งหมด (เหมือน `DateTime` ใน CSV)
- ชั่วโมงที่ไม่มีข้อมูล เส้นบนแผนที่และกราฟจะขาด ไม่ลากต่อกัน
